# 20260518 AI 助理 UI 规格

- Status: accepted for implementation
- Preview: `docs/design/20260518-ai-assistant-preview.html`

## 范围

本规格覆盖 Web 端 AI 助理、实时会议记录、结束会议时 AI 整理确认、我的参会记录、会议纪要详情和纪要分享。微信小程序端不在本轮范围内。

## 菜单与入口

- 底部工具栏新增 `AI 助理`，顺序位于 `聊天` 之后、`参会记录` 之前。
- 底部工具栏新增 `参会记录`，用于注册用户查看自己主持或参会的历史会议。
- 既有 `录制与纪要` 继续保留本地录制和临时纪要导出能力，不承载 AI 纪要。
- 主持人结束会议弹窗保留 `结束会议` 主流程，并新增 AI 整理纪要确认选项。

## AI 助理交互

- 默认状态：实时记录关闭。
- 主持人点击 `AI 助理`：
  - 展示 AI 助理浮层。
  - 浮层包含 `开启实时记录` 主按钮。
  - 点击后开启实时记录，并展示会议记录面板。
- 非主持人点击 `AI 助理`：
  - 不展示浮层。
  - 不采集麦克风。
  - 不上传音频。
  - 固定提示：`该功能只能主持人开启`。
- 实时记录开启后：
  - 所有参会者可见记录状态。
  - 参会端仅上传自己的麦克风音频片段。
  - 会议记录面板按时间、发言人和文本展示转写结果。

## 结束会议交互

- 结束会议弹窗必须由主持人主动触发。
- 如果会议存在转写内容，弹窗展示 `交由 AI 整理会议纪要，完成后邮件发送给主持人` 选项。
- 主持人确认后可以立即关闭会议。
- 后端任务完成后，邮件只发送给主持人。

## 我的参会记录

- 入口名称：`参会记录`。
- 列表展示当前注册用户主持或以注册身份参加过的会议。
- 每条记录至少展示会议标题、会议时间、身份和纪要状态。
- 旧会议或未生成纪要的会议展示 `无会议纪要`。
- 纪要详情展示 Markdown 渲染结果，但后端持久化内容仍是 Markdown 纯文本。

## 纪要分享

- 只有主持人可见分享控件。
- 分享对象只能从该会议的注册参会用户中选择。
- 分享成功后，被分享用户可在自己的参会记录中查看纪要。
- 本轮不提供免登录公开链接。
- 本轮不支持主持人删除纪要。

## 加载态、空态和错误态

- 会议记录空态：`主持人开启 AI 助理后，会在这里实时显示转写内容。`
- 转写失败：在会议记录面板顶部展示低干扰错误提示，不中断会议。
- 纪要生成中：历史记录中展示 `纪要生成中`。
- 纪要生成失败：历史记录中展示 `纪要生成失败`，主持人可查看失败原因摘要。
- 无参会记录：展示 `暂无参会记录`。
- 无可分享用户：分享控件 disabled，提示 `暂无可分享的注册参会用户`。

## 响应式差异

- 桌面端：会议记录面板从右侧浮出，参会记录使用宽弹窗左右布局。
- 移动端 H5：会议记录面板占据可用宽度，参会记录弹窗改为上下布局，会议列表横向滚动。
- 所有按钮文案必须在 360px 宽度下完整可读，不允许互相覆盖。

## 实现核对清单

- `AI 助理` 入口存在且默认关闭。
- 非主持人点击固定提示 `该功能只能主持人开启`。
- 主持人开启后才开始音频采集和上传。
- WebSocket 收到转写段落后可实时追加到会议记录。
- 结束会议弹窗必须由主持人主动确认是否整理纪要。
- 会议关闭后纪要任务仍可后台完成。
- 参会记录只展示当前登录用户有权访问的数据。
- 纪要分享只允许主持人分享给注册参会用户。
